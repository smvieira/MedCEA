Getting a Gmail app password

Gmail does not accept your normal password from other programs. It needs an app password:

  1. Sign in to the Google account that will send the e-mails (a dedicated one is best).
  2. Turn on 2-Step Verification (Security → 2-Step Verification) — app passwords need it.
  3. Open myaccount.google.com/apppasswords, name it medcea, and create it.
  4. Copy the 16 letters into App password here (spaces are fine) and save. The login is checked before it is stored.

The same account sends Keycloak's Forgot password? e-mails, so a change here could redirect password resets. That is why every change waits for a qa person's confirmation before it is used; until then the current account keeps sending. The password is stored in the platform database and is never shown again.
