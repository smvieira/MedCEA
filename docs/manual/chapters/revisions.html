Revision history

This manual is updated at the end of every phase of the IAM plan. Each edition names the code it describes, so a reader can tell whether a page still matches the platform in front of them.

55 Nov 20266520cebIAM Phase 4: the access policy is versioned. Version 1 recorded the factory policy (3 Nov); a git change that would give a role more access is refused before any deploy changes anything, break-glass included; only what drifted is re-rendered (--policy-only, --gate-only). New: the Access Policy at policy.<domain> (matrix with per-cell explanations, history with the chain status, who can…, service identities, break-glass), where an admin drafts and submits a change and a qa person who wrote none of it approves it on the diff the page shows; apps/iam/apply.sh, which verifies the approval on the host (signature, the approver still eligible, the same diff), applies it in one transaction and re-renders only what changes, and rolls back to an earlier confirmed version (confirmed afterwards by another qa person) or audits an applied one; skeleton changes proposed from a git commit; the nightly backup records the history's head. Also: the manual in the portal (Platform manual card), the MedCEA Dashboard card as a chooser of dashboard tools, and exercises E13 to E20. E19 applied and rolled back a first real change on production and found a defect in the audit (fixed). E15 and E13's remaining steps wait for the owner's go-ahead (training chapter).
41 Nov 202673ffd31Release v0.4.0, the code for a fresh installation. New: the Configuration UI's Approvals tab (approve with a note, return, withdraw, history), the parameter-set editor and Retire in place of Delete; test mode (commissioning) of a unit, proposed by an engineer and approved by qa, refused while a run is waiting or running; release of a completed run by qp in the Approvals tab, with a Released badge in the Scheduler; a Training chapter of hands-on exercises; a log in logs/ for every deploy, health check and live test; sessions that follow the person signed in (the AI workbench, Grafana and the Node-RED editor re-check the platform sign-in within minutes; Sign out also ends the workbench); pgAdmin 9.19 with its secrets in a Kubernetes Secret and a ready server entry per administrator; the AI workbench on chart 4.4.4, its setup run before the server starts (notebooks did not open on a new home) and the prompt and git author showing the person; Grafana keeps its data; nightly backups of the databases and every data volume, with restore steps; the shared MQTT Explorer account is removed. A fresh-install review fixed a desktop-session restart during install, anonymous chart pulls, a workbench deploy timeout and the end of the full-enforcement chain. Records and "Last done" dates cited here belong to the install that ran until 1 November 2026.
